Hugging Face 로그인·이용 동의 방법
  1. 실행 서버에서 hf auth login으로 로그인합니다. 처음 한 번 읽기 권한 토큰이 필요하며, 앱에 토큰을 입력하지 않습니다.
  2. Community-1 모델 페이지 ↗를 같은 계정으로 엽니다.
  3. 본인 소속과 용도를 입력한 뒤 Agree and access repository를 누릅니다. 동의하면 계정의 이메일·사용자명이 제작자에게 공유됩니다. 화면의 UNIST는 입력 예시입니다.
  4. 이 창에서 모델 준비하기를 다시 누릅니다. 무료 모델이며 다운로드 후에는 자체 서버에서 실행됩니다.
