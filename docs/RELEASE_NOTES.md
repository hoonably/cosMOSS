- **서버 작업 관리 개선:** 전사 중에도 다른 모델을 선택할 수 있습니다. 같은 GPU의 작업은 순차 처리하고, 다른 GPU의 작업은 동시에 실행합니다.
- **긴 녹음 전사 보강:** Qwen 출력 한도·반복 출력, MOSS 끝부분 누락에 대한 분할·재시도 처리를 추가했습니다.
- **90분 초과 녹음 지원:** 확인을 받은 뒤 최소 개수로 균등 분할해 순차 전사합니다. 100분은 50분씩 2개, 210분은 70분씩 3개로 나눕니다.
- **여러 녹음 이어붙이기:** 여러 파일을 선택하고 드래그로 순서를 정해 하나로 연결한 뒤 전사할 수 있습니다.
- **임시 데이터 정리:** 완료·실패·취소 후 앱이 만든 음성 사본과 분할 파일을 삭제합니다. 결과와 보조 대본은 Downloads에 저장하고, 기존 누적 데이터도 정리합니다.
- **편집 흐름 개선:** 편집 버튼에서 화자 설정을 바로 엽니다. 한 번 클릭하면 선택·방향키 이동, 더블클릭하면 화자 이름이나 본문을 수정합니다.
- **목소리 프로필 제거:** 등록·가져오기·자동 비교·추천 기능과 관련 데이터를 제거했습니다.
- **고정 앱 서명 적용:** 로컬 설치와 공개 업데이트에 같은 인증서를 사용하도록 변경했습니다. 최초 전환 때는 권한 재허용이 한 번 필요할 수 있습니다.
