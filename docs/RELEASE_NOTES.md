## 주요 변경

- 새 버전 자동 알림과 자동 다운로드·설치를 따로 선택할 수 있어요.
- 업데이트 창에서 현재 버전과 확인 상태, 변경 내용을 함께 볼 수 있어요.
- 앱의 설명 글과 대화상자를 더 읽기 편하게 정리했어요.
- 소개 페이지를 간결하게 정리하고 다른 프로젝트로 이동하는 메뉴를 추가했어요.

DMG를 열고 cosMOSS를 응용 프로그램 폴더로 옮겨 설치하세요. 기존 사용자의 노트와 설정은 유지됩니다. 이 문서는 다음 릴리스 초안이며 아직 발행하지 않았습니다.
