# 전사 방식 앱 통합 검증 · 2026-10-21

독립 비교 뒤 사용자의 앱 적용 요청에 따라 구현하고 실제 실행 경로로 재검증했다.
[기존 비교](2026-10-21-h200-asr-comparison.md)의 입력과 모델 revision을 유지했다.
모든 서버 실행은 H200 한 장을 사용하며 양자화하지 않았다.

## 앱의 추천 순서

1. **MOSS · 빠른 전사 + Nemotron**: 기본 추천. 기존 모델과 자체 시간 표시를 유지하며 청크 동시 처리로 시간을 줄인다.
2. **Qwen3-ASR + ForcedAligner + Nemotron**: 더 빠르게 처리하고 싶을 때 선택한다. 메모리가 더 필요하며 단어 시간과 전문 용어를 확인해야 한다.
3. **MOSS · 긴 문맥**: 긴 청크를 순서대로 처리하는 기존 방식이다. 짧게 나눈 결과와 문맥을 비교할 때 남겨 두었다.

이 순서는 사용 편의·속도·메모리의 절충이며 한국어 정확도 순위가 아니다.
텍스트를 직접 비교했지만 독립적인 원음 청취 정답이나 CER/WER/DER 평가는 없다.
두 전사 모델은 전문 용어와 짧은 마지막 발화를 다르게 인식하기도 한다.

## 실제 앱 실행 코드 재측정

입력은 65분 37.1306875초, 약 3분의 저에너지 경계 23청크다.
모델·정렬·화자 모델이 같은 GPU에 함께 올라간다.

| 실제 실행 경로 | 동시 청크 | 모델 처리 | 로딩·초기화 | 프로세스 Peak VRAM | PyTorch 예약 Peak |
|---|---:|---:|---:|---:|---:|
| MOSS + Nemotron | 23 | 77.32초 | 11.16초 | 17.89 GiB | 17.21 GiB |
| Qwen + ForcedAligner + Nemotron | 23 | 45.59초 | 12.68초 | 31.34 GiB | 30.67 GiB |

모델 처리에는 입력 특징 처리·전사·정렬·Nemotron·화자 연결이 포함된다.
다운로드·음성 전송·파일 변환은 제외한다. Peak는 작업 PID를 약 0.5초마다 관측한다.
Qwen은 짧은 입력으로 초기화한 뒤 임시 CUDA 예약 블록을 해제한다.
초기화 없이 처음부터 큰 배치를 실행하면 같은 출력이라도 예약 Peak가 약 42.3 GiB로 커지는 것을 확인해 실행 경로를 수정했다.

앱 API 전체 통합 검증에서는 실제 파일 업로드 → 전처리 → MOSS 빠른 전사 → SRT 저장까지 완료했다.
전처리 후 작업 전체는 **94.285초**, 그중 모델 처리 **77.243초**, 로딩·초기화 **11.100초**였다.
나머지는 서버 연결·음성 전송·결과 수신·저장 등의 시간이다. 네트워크와 캐시에 따라 달라진다.
Qwen도 실제 앱 API에서 VTT 저장까지 완료했으며, 작업 전체 **64.973초**, 모델 처리 **45.864초**였다.

## 화자·원문 보존

- 두 구성에서 Nemotron은 같은 6개 목소리를 찾았다. 주 발화자 3명과 지나가는 사람을 고려하면 3명을 정답으로 고정할 수 없다.
- Qwen 정렬에는 6,074개 단어 중 699개의 0초 구간이 있었다. 해당 시점에 한 목소리만 활성화되어 있을 때만 연결하며, 가까운 화자로 추측하지 않는다.
- 음성이 겹치거나 연결 근거가 부족하면 `미확인`으로 표시한다. MOSS는 146개 발화, Qwen은 편집용으로 묶은 332개 발화가 확인 대상으로 남았다. 구간 단위가 달라 정확도 비교 수치로 사용할 수 없다.
- Qwen의 원래 ASR 문자열과 편집용 본문의 숫자·영문·한국어 문자 순서가 동일함을 확인했다. 원래 문자열·단어 시간·화자 구간은 노트의 비공개 진단 파일에 별도 보관한다.
- 이후 화자 재분리·이름 추천은 전후 비교 후 선택 승인한다. `미확인` 구간을 하나의 실제 화자로 취급해 목소리 프로필을 만들지 않는다.

## 검증 범위

- 같은 서버 계정의 기존 MOSS 환경을 수정하지 않고 별도 버전 환경에 두 구성을 준비했다. Mac에는 새 전사 가중치를 설치하지 않았다.
- GPU UUID 잠금, 작업별 프로세스 그룹, SSH heartbeat, Linux parent-death guard를 적용했다.
- 실제 추론 중 연결을 종료하자 **약 1.47초** 안에 해당 GPU 프로세스가 종료됐다. 다른 작업을 종료하는 명령은 사용하지 않았다.
- 서버 임시 입력·결과 폴더가 정리되고 테스트 GPU 작업이 남지 않은 것을 확인했다.
- 자동 배치·70% 경고·GPU 변경·기존 청크 방식·화자 부분 승인·원문 보존을 검증했다.
- Chrome·WebKit에서 1440/1100/390px 레이아웃, 기본 선택·추정값·메모리 경고·모드 전환을 확인했다.
- 단위·API 검증 253개가 통과했다. Qwen의 전체 앱 API 경로도 실제 녹음으로 실행해 VTT 저장까지 확인했다.
- 개발용 Mac 앱 빌드와 서명 검증을 완료했다. 커밋·푸시·릴리스 배포는 하지 않았다.

숫자는 같은 녹음의 관측값이다. 다른 음성의 발화 밀도·언어·GPU·모델 캐시에 대한 성능 보장은 아니다.
