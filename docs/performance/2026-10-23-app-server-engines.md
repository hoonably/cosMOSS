# 서버 전사 엔진 통합 · 2026-10-23

Mac은 기존 MOSS MLX만 사용한다. 서버 선택은 다음 세 가지다.

| 선택 | 실제 단계 | 본문 |
| --- | --- | --- |
| MOSS · SGLang Omni · 전체 (추천·기본값) | 전체 MOSS → 해제 → Nemotron | MOSS 시간·대본 + Nemotron 화자 |
| Qwen · Transformers · 3분 + 정렬 | SDK 약3분 전사 → 해제 → 정렬 → 해제 → Nemotron | 정렬 단어를 발화로 묶은 대본 |
| MOSS + Qwen · 순차 실행 | 전체 MOSS → 해제 → SDK 약20분 Qwen → 해제 → Nemotron | MOSS 본문 유지, Qwen 보조 대본 별도 |

전체 MOSS는 최대90분이다. 청크 개수 UI를 노출해 문맥을 임의로 자르지 않는다.
Qwen 3분 전사는 동시 청크 수를 자동 또는 직접 지정한다.
보조 Qwen은 한 번에 최대4청크로 제한한다. 정렬·화자 시각은 붙이지 않으며,
완료 노트의 펼침 영역과 TXT 다운로드로 확인한다. 본문 자동 수정·LLM 병합은 하지 않는다.

## 실행 설정

- `speech_engines.py`: 패키지·모델 revision·단계 순서 고정.
- SGLang Omni0.1.9 / SGLang0.5.22 / Torch2.14.1 / Transformers5.19.0.
  MOSS BF16, KV131072토큰(14GiB), mem_fraction_static0.4. 시스템 CUDA를 바꾸지 않고 환경 내부 CUDA13 컴파일러를 사용한다.
- Qwen SDK0.0.6 / 원본Qwen3-ASR-1.7B / Transformers4.57.6 / Torch2.9.1 / FA2 2.8.3.
  중첩 Attention 설정까지 FA2, BF16. 3분 출력 한도4096, 20분8192.
  원본 토큰의 EOS·한도·긴 반복을 확인하고 SDK 원문과 함께 보관한다.
- 정렬기는 별도 프로세스에서 ASR 관측 피크보다 작은 allocator 예산을 사용한다.
  1개부터 시작해 관측 메모리에 맞춰 배치를 늘리고 예산 부족 시 줄인다.
- Nemotron은 Torch2.8.0 / Transformers5.20.2 / FP32 SDPA, 전체 녹음을 offline(340,40) 모드로 한 번 처리한다.
- 단계마다 프로세스 그룹을 종료하고 GPU 작업 해제를 확인한 후 다음 모델을 올린다.
  GPU UUID 잠금·SSH 생존 신호·stage parent-death guard를 사용한다.
- 새 환경은 공통 서버 계정 폴더에 보관하며 기존 앱·실험 환경은 수정하지 않는다.
  연결과 모델 선택만으로 설치하지 않고 명시적인 다운로드로 준비한다.

초기 예상은 기존 65분37초 실측을 참고한다. MOSS는 KV 제한 실행의 단계 시간 합산을
사용하며, 이전 무제한 KV 엔진의 더 짧은 초기화 시간을 그대로 가져오지 않는다.
실제 완료 시 같은 GPU 이름·메모리 등급·런타임·프리셋·배치의 숫자 지표만 누적한다.
모델 준비·import·해제 시간도 보정에 포함하고 설치·전송은 제외한다.

## 검증

- juyu-h200 GPU0에서 앱의 실제 `SpeechJobs.execute` 경로로 60초 음성을 세 방식 모두 완료했다.
  설치·inspect·전사·정렬·화자 연결·순차 해제를 확인했다. 세 결과 모두18개 발화를 반환했다.
  이 짧은 호환성 시험을 장시간 한국어 품질 평가나 속도 순위로 사용하지 않는다.
- 65분 녹음의 Qwen 추론이 시작된 뒤 연결을 취소하자 약1.64초 안에 해당 GPU PID가 종료됐다.
- SSH supervisor SIGKILL을 모사한 CPU 시험에서도 stage와 하위 프로세스가 약0.02초 안에 종료·회수됐다.
- 단위·API 검증, Chrome·WebKit의 모델 선택·메모리 경고·제출·1440/1100/390px 화면을 확인했다.
  보조 대본은 펼치기 전에는 가져오지 않고, 본문을 유지하며, TXT 노트로 전환하면 숨긴다.
- 개발용 Mac 앱 빌드·서명 검증 후 실행 중인 앱 API에서 새 기본값과 세 가지 메뉴를 확인했다.
- 기존 서버 장치의 기본 프리셋은 앱 시작 시 대응하는 새 방식으로 전환한다.
  이전 노트의 스냅샷과 실행 코드는 유지한다. Mac 모델·KV 설정은 변경하지 않는다.

비공개 검증 원본·실행 로그·이미지는 작업 공간의 `work/app-engine-integration/`에 보관한다.
앱 소스에 개인 음성·대본을 추가하지 않았으며, 커밋·푸시·릴리스 배포는 하지 않았다.
