A FEW GOOD QUESTIONS

궁금한 점이
있으신가요?

문제 제보하기 ↗
GPU 서버가 꼭 필요한가요?

아니요. Apple Silicon Mac에서 MOSS MLX와 Nemotron으로 전사와 화자 구분을 처리할 수 있습니다. NVIDIA GPU 서버가 있다면 SSH로 연결해서 사용할 수도 있습니다.

어떤 파일을 가져올 수 있나요?

MP3·WAV·M4A·MP4 등 음성·영상 파일과 Mac 음성 메모를 지원합니다. 이미 전사한 TXT·SRT·VTT 파일도 불러와 편집할 수 있습니다.

음성이나 전사문이 외부로 전송되나요?

이 Mac에서 전사하면 해당 Mac에서 음성을 처리합니다. 원격 전사를 선택하면 선택한 서버로 음성을 보내며, AI 요약을 실행하면 선택한 AI 서비스로 전사문을 전달합니다. 처음 도구와 모델을 준비할 때는 인터넷 연결이 필요합니다.

화자 구분이 틀리면 고칠 수 있나요?

네. 발화를 직접 재생해 듣고 이름을 수정하거나 화자를 병합할 수 있습니다. 화자 재분리와 목소리 이름 추천도 변경 전후를 검토하고 승인한 항목만 반영합니다.

AI 요약은 어떻게 사용하나요?

이 Mac에 설치하고 로그인한 Codex 또는 Claude CLI 계정을 사용합니다. 2단계에서 노트를 선택한 뒤 3단계에서 보정·요약을 실행하세요. 기본 프롬프트를 수정하거나 추가 요청을 붙일 수 있습니다.

처음 실행할 때 무엇을 준비해야 하나요?

앱의 안내에 따라 전체 디스크 접근 권한을 허용하고, 설정에서 FFmpeg·FFprobe를 준비합니다. 그다음 사용할 장치의 전사 모델을 선택해 다운로드하세요. 서버만 사용한다면 Mac용 전사 모델은 필요하지 않습니다. 마이크 권한은 목소리 프로필을 녹음할 때 요청합니다.
